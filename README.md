# Файлы команды в GitLab

Прототип расширения Chrome для просмотра изменений МР на `raketa.dev` по секциям CODEOWNERS.

## Установка

1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку `gitlab-mr`.
3. Откройте страницу МР в авторизованной сессии GitLab. Обновите вкладку, если она уже была открыта.
4. Нажмите «Файлы команды» в правом нижнем углу. Выберите секцию CODEOWNERS и файл.

Выбор секции запоминается для проекта. Поиск работает по старому и новому пути файла. Кнопка «Обновить» загружает текущий diff после новых коммитов в МР.

Расширение запрашивает `raw_diffs` и читает первый доступный CODEOWNERS из целевой ветки в порядке GitLab. При переименовании файл попадает в секции обоих путей. Браузер использует текущую сессию GitLab. Все запросы идут на `raketa.dev`.
