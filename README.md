# Файлы команды в GitLab

Расширение Chrome добавляет фильтр по секциям CODEOWNERS в штатную вкладку Changes на `raketa.dev`.

## Установка

1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку `gitlab-mr`.
3. Откройте страницу МР в авторизованной сессии GitLab. Обновите вкладку, если она уже была открыта.
4. Откройте вкладку Changes и отметьте нужные секции в меню CODEOWNERS.

В списке изменений остаются файлы из любой отмеченной секции. Пункт «Все файлы» сбрасывает фильтр. Выбор секций запоминается для проекта.

При активном фильтре боковая панель показывает компактное дерево подходящих файлов. Поиск по путям поддерживает простые маски с `*` и `?`. В режиме одного файла между совпадениями можно переходить через дерево или список «Перейти к файлу…».

Подсветка, комментарии и режимы просмотра diff работают в штатном интерфейсе GitLab.

Для фильтра расширение читает метаданные файлов из Changes и первый доступный CODEOWNERS из целевой ветки в порядке GitLab. Для переименованных файлов учитываются оба пути. Браузер использует текущую сессию, запросы идут на `raketa.dev`.
